📘 ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ)

Проект: Android-приложение FastScan
Пакет: com.ocr.fastscan
Платформа: Android 8+ (minSdk 24)

1. Цель проекта

Создать мобильное Android-приложение, которое:

Открывает сайт компании во встроенном WebView

Автоматизирует ввод данных в три поля сайта:

поле поиска / трек-кода

поле ввода KG-кода (например: KG123456)

поле ввода веса (числовое значение с точкой)

Позволяет пользователю сканировать:

штрихкод / QR код (штрихкод товара)

текстовый KG-код с этикетки (OCR)

показания электронных весов (OCR только цифры)

После сканирования автоматически:

вставляет найденное значение в нужное поле формы на сайте

нажимает Enter или вызывает событие ввода на сайте

возвращает курсор обратно на первое поле

Обеспечивает полностью ручное управление через 3 кнопки в интерфейсе:

Scan Barcode

Scan KG

Scan Weight

2. Описание рабочего процесса
2.1. Цикл работы (основной сценарий)

Приложение открывает WebView → автоматически загружает сайт.

Курсор автоматически находится в поле для сканирования штрихкода.

Пользователь нажимает кнопку “Barcode”:

включается камера → происходит сканирование штрихкода

найденное значение вставляется в первое поле

делается задержка 1–2 сек (сайт выполняет поиск)

выполняется Enter (или JS submit)

Пользователь нажимает “KG”:

камера → фотография этикетки

OCR ищет KGxxxxxx

 значение xxxxxx автоматически вставляется в поле "Код клиента" (только цифры)

выполняется Enter

Пользователь нажимает “Weight”:

камера → OCR цифрового веса

значение вставляется в поле “weight”

выполняется Enter

Курсор возвращается в первое поле (поиск по треку)

Цикл повторяется.

3. Интерфейс приложения
3.1. Основной экран

Элементы:

● WebView (во весь экран)

Загружает рабочий сайт

Разрешён JavaScript

Возможность выполнения JS-команд для вставки текста в поля

● Три FloatingActionButton:

fabBarcode – запуск сканирования штрихкода

fabKg – запуск OCR для KG

fabWeight – OCR веса

Расположение кнопок:

Внизу слева, снизу-по-центру и снизу справа.

4. Авторизация на сайте

Приложение должно поддерживать автоматическую авторизацию на сайте:

Логин и пароль хранятся локально в SharedPreferences.

При первом запуске пользователь вводит Логин/Пароль.

WebView автоматически заполняет поля формы логина через JS.

Выполняется нажатие кнопки «Войти».

5. Сканирование и распознавание
5.1. Штрихкоды

Используется MLKit BarcodeScanning

Поддерживаемые типы: EAN-13, Code128, QR и т.д.

На выходе используется первое найденное значение.

5.2. KG-коды

CameraX → фото → MLKit Text Recognition

Регулярное выражение:

KG\d{4,6}

5.3. Вес

CameraX → MLKit OCR

Регулярное выражение:

\d+\.\d+


или любая последовательность цифр с точкой.

6. Работа с WebView
6.1. Заполнение полей

Приложение вставляет текст через JavaScript:

Находит нужное поле по:

id

placeholder

class

Устанавливает .value = "текст"

Вызывает событие:

element.dispatchEvent(new Event('input'))
element.dispatchEvent(new Event('change'))

# FastScan Telegram Bot

Исходный код перенесён из работающего `@LmsMalagaBot` без удаления готовых сценариев. Бот станет частью единой FastScan Warehouse Platform и будет работать с FastScan API/PostgreSQL.

## Состояние миграции

- Сохранены регистрация, меню ролей, приёмка, сканирование, фотографии, заказы, посылки, коробки, клиенты, финансы, товары, заметки и история.
- Telegram token хранится только в локальном `bot/.env` и исключён из Git и Docker build context.
- Старый LMS backend отключён; до запуска бота его API-адаптер должен быть переключён на FastScan API.
- Первый рабочий этап: Telegram-only регистрация клиента и одноразовая ссылка входа в FastScan Web.
- Следующие этапы: последовательная адаптация складских обработчиков к маршрутам `/api/mobile/*`, `/api/staff/*` и `/api/admin/*`.

Не запускайте одновременно старый и новый экземпляры с одним token: Telegram polling должен выполнять только один процесс.

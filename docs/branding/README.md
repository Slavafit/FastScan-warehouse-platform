# FastScan brand icon

The primary FastScan mark combines a parcel, scanner corners, and a forward arrow.

- Primary background: `#102A43`
- Production accent: `#FF7A00`
- Development accent: `#22D3EE`
- Symbol: white

The orange version is used by FastScan Platform and FastScan Pro. The cyan version is reserved for Android Debug builds installed as FastScan Dev.

Android launcher assets use the same mark at 68% scale on a white background so adaptive launcher masks do not crop the symbol.

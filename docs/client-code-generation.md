# Random client codes / Случайные номера клиентов

Номер клиента создаётся сервером автоматически. Администратор настраивает только префикс, а числовая часть генерируется случайно.

## Формат

При стандартном префиксе `KG` коды выглядят так:

```text
KG482731
KG105824
KG793160
```

- `KG` — настраиваемый администратором префикс;
- шесть цифр — случайное число от `100000` до `999999`.

Для генерации используется криптографически стойкий `SecureRandom`. Перед сохранением сервер проверяет уникальность кода и повторяет генерацию при совпадении. В базе данных поле `client_code` дополнительно защищено ограничением `UNIQUE`.

## Настройка администратора

```text
GET /api/admin/client-code-settings
PUT /api/admin/client-code-settings
Authorization: Bearer <admin-access-token>
```

Пример изменения префикса:

```json
{
  "prefix": "FS"
}
```

Ответ:

```json
{
  "prefix": "FS",
  "code_format": "FS######"
}
```

Префикс содержит от 1 до 12 латинских букв, цифр или дефисов и сохраняется в верхнем регистре. Изменение префикса не меняет уже созданные клиентские номера.

## Создание клиента

```text
POST /api/common/reciever
Authorization: Bearer <admin-or-worker-access-token>
```

```json
{
  "first_name": "Anna",
  "last_name": "Client",
  "package_shoes": 0,
  "bag_package": 0
}
```

Ответ содержит созданный код:

```json
{
  "guid": "…",
  "client_code": "FS482731",
  "full_name": "Anna Client",
  "package_shoes": 0,
  "bag_package": 0
}
```

Поле `client_code` по-прежнему можно передать явно для импорта старых клиентов и совместимости с существующими данными.

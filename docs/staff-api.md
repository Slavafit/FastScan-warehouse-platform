# Роль сотрудника и манифесты

В платформе используются ровно три роли:

- `ADMIN` — настройки платформы и управление учетными записями сотрудников;
- `WORKER` — складские операции, исправление данных клиентов и создание манифестов;
- `CLIENT` — личный кабинет клиента.

Отдельной роли менеджера нет. Ее рабочие функции входят в роль `WORKER`.

## Учетные записи сотрудников

- `GET /api/admin/users` — список администраторов и сотрудников;
- `POST /api/admin/users` — создание сотрудника с ролью `WORKER`.
- `PUT /api/admin/users/{id}/enabled` — блокировка или разблокировка сотрудника.

## Клиенты

- `GET /api/staff/clients` — список клиентов;
- `PUT /api/staff/clients/{guid}` — изменение имени, телефона, адреса, email и настроек упаковки.

Код клиента через этот метод не изменяется.

## Манифесты

- `GET /api/staff/manifests` — список манифестов;
- `POST /api/staff/manifests` — создание манифеста для завершенной партии.

Манифест содержит снимок всех заказов из всех коробок партии, данные клиентов и итоговые значения. Для одной партии создается один манифест: повторный запрос возвращает уже существующий результат.
